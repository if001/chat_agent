# User Memory

Use this skill only for an explicit request to inspect or change reusable user context.

## Procedure
1. Search first so a matching note and its ID are known.
2. Save only a new stable preference, constraint, or ongoing work premise.
3. Correct the matching note in place; never add its contradiction.
4. Delete only the matching searched ID requested by the user.

Do not guess note IDs. Date-specific events, proactive-topic reactions, response
strategies, and conversation transcripts belong elsewhere.
